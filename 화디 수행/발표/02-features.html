구현 기능 설명
사용자가 이 사이트에서 무엇을 ‘할 수 있는지’ — 6가지 핵심 기능
01

화면 전환

새로고침 없이 7개 화면을 부드럽게 이동. location.href 라우팅 + fadeIn 0.5s 트랜지션.

02

데이터 상태 저장

5개의 답을 sessionStorage에 키–값으로 누적 저장. 결과 화면에서 한꺼번에 꺼내 매칭에 사용.

03

태그 기반 매칭 알고리즘

모든 곡과 5개 답을 비교해 일치 태그 개수(점수)를 매기고 최고점 곡을 반환. 곡당 5점 만점.

04

앨범 커버 셔플 애니메이션

홈에서 setInterval 1초마다 27장의 앨범 커버를 무작위 교체. @keyframes floatBounce 로 둥둥 떠오름.

05

YouTube iframe 재생

결과 화면이 매칭 곡의 youtubeId로 embed URL을 만들어 iframe에 주입 → 클릭시 재생.

06

선택지 호버 트랜지션

버튼에 마우스 올리면 scale(1.02) + 네온 그린 보더. 진행바도 width 0.4s ease로 부드럽게 늘어남.
